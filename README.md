# بوت تيليقرام للتحميل السريع (يوتيوب + إنستقرام + تيك توك)

بوت تيليقرام سريع جداً لتحميل مقاطع **YouTube** و **Instagram** و **TikTok** تلقائياً بأعلى جودة متاحة، مع دعم رفع ملفات كبيرة حتى **2 جيجابايت** مباشرة عبر MTProto (`Pyrofork` + `TgCrypto`).

## المميزات
- **تحميل تلقائي فوري** بمجرد إرسال الرابط (بدون أزرار).
- **أعلى جودة متاحة** مع دمج الصوت والفيديو عبر `FFmpeg` بدون إعادة ترميز (`+faststart` للتشغيل الفوري).
- **دعم حتى 2GB** لرفع الفيديوهات الطويلة وعالية الدقة.
- **تيك توك بدون علامة مائية** + دعم **ألبومات إنستقرام** (صور وفيديوهات متعددة).
- **سرعة عالية** عبر التحميل المتعدد الأجزاء (`concurrent_fragment_downloads`) وتشفير `TgCrypto` المكتوب بلغة C.
- **مؤشر تقدم مباشر** يظهر نسبة وسرعة التحميل والرفع.

## خطوات الإعداد والتشغيل

### 1. استخراج بيانات تيليقرام المطلوبة
1. **توكن البوت (`BOT_TOKEN`)**:
   - افتح [@BotFather](https://t.me/BotFather) في تيليقرام ← أرسل `/newbot` ← اتبع الخطوات وانسخ التوكن.
2. **`API_ID` و `API_HASH`** (لفتح حد الرفع إلى 2GB):
   - ادخل على [my.telegram.org](https://my.telegram.org) وسجل دخولك برقمك.
   - اضغط على **API development tools** وأنشئ تطبيقاً (أي اسم)، ثم انسخ `App api_id` و `App api_hash`.

### 2. إعداد ملف `.env`
انسخ ملف `.env.example` إلى `.env` وضع بياناتك فيه:
```env
API_ID=12345678
API_HASH=your_api_hash_here
BOT_TOKEN=1234567890:your_bot_token_here
```

### 3. تشغيل البوت
من داخل مجلد المشروع:
```powershell
.venv\Scripts\python.exe run.py
```
أو بالضغط المزدوج على ملف `start.bat`.

## ملاحظات مهمة
- **مقاطع إنستقرام أو يوتيوب المقيدة**: إذا أردت تحميل مقاطع تتطلب تسجيل دخول (مثل بعض منشورات إنستقرام أو مقاطع يوتيوب المقيدة بالعمر)، صدّر ملف الكوكيز من متصفحك باسم `cookies.txt` (بصيغة Netscape) وضعه في مجلد المشروع، وسيتعرف عليه البوت تلقائياً.
- **تحديث `yt-dlp` مستقبلاً**: يوتيوب وتيك توك يحدثان أنظمتهما باستمرار، لذا عند حدوث أي مشكلة في التحميل حدّث `yt-dlp` بالأمر:
  ```powershell
  .venv\Scripts\pip.exe install -U "yt-dlp[default]"
  ```
- **أمر `/status`**: أرسله للبوت للتحقق من توفر `FFmpeg` و `Node.js` و `TgCrypto` وعدد التحميلات النشطة.
